# 墨玉UI

墨玉UI 设计体系相关的开源资源与演示合集。

## 目录结构

```
墨玉ui/
├── ui-resources/   UI 设计素材库（开源 UI 素材、图标、主题、设计源文件）
│   ├── 01_UI-Research_开源UI素材/    Penpot / GitLab Pajamas / 图标集 / ECharts 主题 / Figma 资源链接
│   ├── 02_Cline_Orb界面资源/         AI Orb 状态球界面资源（Figma 包、图标、原型、切图）
│   ├── 03_AI-Employee-OS界面资源/    AI-Employee-OS 界面素材（线性图标、主题配置）
│   ├── 04_companion-ui-engineer_skill/  UI 工程师能力说明
│   └── 00_清单.md                    素材库复制与校验清单
└── html-demos/      HTML 界面演示（可直接浏览器打开）
    ├── 墨玉UI设计系统.html           墨玉UI 设计系统规范页
    ├── 墨玉UI主题生成器.html
    ├── 墨玉UI款式实验室.html
    ├── 墨玉UI代码工具箱.html
    └── 其他界面演示（Dashboard 菜单、Claude 手感复刻、神经网络光球等）
```

## 说明

- `ui-resources/` 内各子目录素材保留其原始开源许可证（详见各目录自带 LICENSE / _resources.md）。
- `html-demos/` 为纯前端演示页面，双击即可在浏览器打开。
- 本仓库默认采用 MIT 许可证，如需调整请联系作者。

## 使用方式

```bash
git clone https://github.com/ve766/墨玉ui.git
```

打开 `html-demos/` 下任意 `.html` 文件即可预览界面演示。
