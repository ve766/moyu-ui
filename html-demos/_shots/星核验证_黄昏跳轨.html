    这次迭代，把「信息结构」本身设计成空间

    沿 Xuan子 的审美与方法（银灰底、香槟金、光球、神经流光、一轮一改），但不再复现任何既有界面——以下是四个设计决策。

    信息架构 · 侧边栏 → 轨道行星

    模块=列表项模块=行星：优先级不是数字，而是距光核的轨道——内轨=高优先、外轨=低优先，一眼看清资源该投给谁。

    状态显示 · 指示灯 → 光核

    徽标/彩色圆点整个中枢的光：光核颜色与呼吸编码创作阶段（灵感暖金 / 写稿银白 / 发布香槟 / 复盘冷青），状态即光。

    环境氛围 · 固定背景 → 24h 光影循环

    一张背景图时刻即氛围：背景、光核、行星阴影随时刻流转——清晨冷、正午烈、入夜沉，界面会"过一天"。

    优先级管理 · 菜单/排序 → 行星跳轨

    在下拉框里选把行星拖上另一条轨道：管理即动作，改优先级变成一次有动效的位移。

    星核创作中枢为原创 UI 设计（本会话设计，非任何视频复现）：在 Xuan子 系列「创作面板 + 神经网络看板」的光球/水母语言基础上，将信息架构、状态表达、环境氛围与优先级管理重构为轨道空间系统。行星数据全部虚构。
