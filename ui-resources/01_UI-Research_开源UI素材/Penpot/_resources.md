## 四、备注

- 导入方式：Penpot → 工作区 → Import 选择 .penpot 文件，导入后可转为共享库使用（见 https://help.penpot.app/user-guide/import-export/ ）。
- 仓库根 `.gitattributes` 声明 `*.penpot filter=lfs`，所有 .penpot 经 Git LFS 托管；raw 链接下载即为完整设计包。
- 本目录仅做素材搜集，未进行任何产品代码编写或界面设计。
